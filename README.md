# design-skills-sandbox

Claude Code skills installed in `.claude/skills/`:

- **taste-skill** — Anti-slop frontend design taste skill. Source: [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT).
- **impeccable** — Paul Bakaus's design language/critique toolkit (17 commands: audit, critique, polish, simplify, animate, etc). Source: [pbakaus/impeccable](https://github.com/pbakaus/impeccable) (Apache-2.0).
- **animate**, **animation-vocabulary**, **find-animation-opportunities**, **improve-animations**, **review-animations** — Emil Kowalski's animation philosophy, split into build/audit/critique/vocabulary skills. Source: [emilkowalski/skills](https://github.com/emilkowalski/skills) (MIT).
