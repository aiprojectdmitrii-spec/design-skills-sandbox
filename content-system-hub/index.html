Как модули связаны между собой

Каждый этап получает результат предыдущего и передает свой следующему. Ниже вся цепочка целиком, дальше разберем каждый модуль отдельно.

01 Идея и сценарий Claude 02 Визуал Midjourney 03 Видео Remotion 04 Автоматизация n8n 05 Дистрибуция Telegram, IG

Модуль 01

Идея и сценарий

Claude превращает бриф, тему или ссылку в готовый сценарий: структуру, реплики, тайминг и раскадровку по сценам.

Cl

Claude

Пишет сценарий и раскладывает его на сцены по заданной структуре.

Px

Perplexity

Проверяет факты и подбирает свежие источники под тему выпуска.

No

Notion

Хранит сценарии, версии и комментарии команды в одном месте.

Готовый сценарий уходит в модуль Визуал как техническое задание для кадров.

Раскладка сценария 4 сцены · 0:28
0:00-0:04

Хук

Цепляющий вопрос или факт, ради которого досмотрят дальше.

0:04-0:12

Завязка

Формулируем проблему языком зрителя, без вступлений.

0:12-0:22

Разбор

Показываем решение по шагам с конкретными деталями.

0:22-0:28

Призыв

Одно четкое действие: куда перейти или что сделать дальше.

Модуль 02

Визуал

Сценарий превращается в раскадровку: обложки, кадры и стиль подбираются под каждую сцену отдельно.

Mj

Midjourney

Генерирует кадры и обложки в едином визуальном стиле по референсам.

Id

Ideogram

Встраивает читаемый текст и заголовки прямо в изображение.

Cv

Canva

Быстро адаптирует готовые кадры под формат каждой площадки.

Кадры и обложки передаются в модуль Видео как исходники для монтажа.

Rm

Remotion

Собирает видео из React-компонентов и рендерит финальный файл.

EL

ElevenLabs

Озвучивает сценарий синтетическим голосом на нужном языке.

CC

CapCut

Дорабатывает ритм и вносит ручные правки поверх рендера.

Модуль 03

Видео

Remotion собирает ролик из кода: кадры, титры и переходы описываются компонентами и рендерятся без ручного монтажа в таймлайне.

Готовый ролик попадает в модуль Автоматизации вместе с текстом поста.

Модуль 04

Автоматизация публикации

n8n связывает модули в один сценарий: получает файлы, ставит их в календарь и запускает публикацию без ручных действий.

n8n

Забирает видео и текст поста

n8n

Оркестрирует сценарий и связывает остальные инструменты между собой.

Sh

Ставит выпуск в календарь

Google Sheets

Служит контент-календарем с датами, статусами и площадками.

Cr

Запускает публикацию по расписанию

n8n · Schedule Trigger

Встроенный триггер n8n срабатывает точно по времени, без сторонних сервисов.

По этому триггеру n8n напрямую обращается к Bot API и Graph API модуля Дистрибуции.

Модуль 05

Дистрибуция

Один и тот же ролик адаптируется под формат каждой площадки и уходит зрителю без правок вручную.

Tg

Telegram

Публикует в каналы через Bot API, включая опросы и реакции под постом.

Ig

Instagram

Выкладывает Reels и карусели через Graph API с подписью и тегами.

Просмотры и реакции этого выпуска вручную или через Notion становятся вводными для следующего сценария: цикл замыкается заново.

Вместе это работает как система, а не пять отдельных инструментов.

Каждый модуль передает результат следующему: текст становится кадром, кадр становится видео, видео становится публикацией. Правка в сценарии автоматически меняет то, что окажется в ленте.

Собирайте модули по одному: систему можно запустить и с ручным монтажом, добавляя автоматизацию позже.
